# AVAND / TYPE

Versión preparada para desplegar en Vercel.

## Contenido
- Archivo tipográfico AVAND / TYPE
- Laboratorio EXPERIMENTA con las fuentes del archivo
- Cursor experimental
- Academia
- Enlace a Explorando Letras
- Secciones de proyectos, AVAND y contacto
- Fuentes locales incluidas en `public/fonts`

## Despliegue en Vercel
1. Descomprime este archivo.
2. En Vercel selecciona **Add New Project**.
3. Importa/sube la carpeta del proyecto `avand-type-vercel`.
4. Framework: Next.js (detección automática).
5. No agregues variables de entorno.
6. Despliega.

El proyecto no depende de una base de datos ni de servicios externos para funcionar.
